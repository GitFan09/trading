# Parkett Daytrading

Übungs-App für Daytrading mit virtuellem Geld, gebaut für das iPhone (läuft in jedem Browser).

- Krypto und EUR/USD: echte Echtzeit-Kurse von Binance (öffentliche Marktdaten, kein Schlüssel nötig).
- Forex, Rohstoffe, Indizes, Aktien: echte Kurse über einen eigenen kostenlosen Finnhub-Schlüssel, der in der App eingetragen wird und nur auf dem Gerät bleibt. Ohne Schlüssel sind diese Märkte simuliert und so markiert.
- Konto, Trades und Lernfortschritt liegen im Browser-Speicher des Geräts.

Keine Anlageberatung. Es wird kein echtes Geld gehandelt.
